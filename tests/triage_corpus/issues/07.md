# Dashboard page feels slow sometimes

The dashboard page feels sluggish to load sometimes. I haven't
been able to nail down exactly when — it's fine most of the time, then
every so often (maybe 1 in 10 loads?) it takes 4-5 seconds before the
dependency graph shows up. No spinner, just a blank panel.

I tried to repro with the network tab open and the `/graph` request
came back in ~200ms even on the slow loads, so it's not the API. Might
be a client-side render thing. I haven't profiled it.

A couple of people on the team have mentioned the same thing in
standup but nobody's been blocked by it.

Not sure if this is worth fixing yet — wanted to log it so we have a
record.

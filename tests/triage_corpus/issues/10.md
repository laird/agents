# Tooltip on "Confidence" column header has a typo: "Confidance"

The tooltip that appears when you hover the "Confidence" column header on
the hypothesis table reads:

> The Confidance score reflects the cumulative credibility of the
> evidence supporting this hypothesis.

Should be "Confidence." Only the tooltip is affected — the column header
itself and all the underlying data are spelled correctly.

Edge case: the tooltip only renders if you hover for >500ms, so most
users never see it. Caught while taking screenshots for a customer demo.

Truly trivial — string-literal fix in one component file.

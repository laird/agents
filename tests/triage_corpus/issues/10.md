# Tooltip on "Priority" column header has a typo: "Priortiy"

The tooltip that appears when you hover the "Priority" column header on
the metrics table reads:

> The Priortiy score reflects the cumulative weight of the
> factors supporting this item.

Should be "Priority." Only the tooltip is affected — the column header
itself and all the underlying data are spelled correctly.

Edge case: the tooltip only renders if you hover for >500ms, so most
users never see it. Caught while taking screenshots for a customer demo.

Truly trivial — string-literal fix in one component file.

# Deliverable PDF export blocked: all exports fail with "font not found"

The "Export Deliverable as PDF" button on the engagement detail page is
broken for all users. Clicking it shows a toast "Export failed — please
retry" and the backend logs show:

```
[pdf-worker] Error: Unable to locate font file 'Inter-Regular.ttf'
  at PdfRenderer.loadFont (pdf-renderer.ts:84)
```

The font file appears to have been removed from the Docker image in the
last release.

Impact: PDF export is the single most-used deliverable format — most
clients want the report as a PDF, not as the in-app HTML view. There is
**no in-app workaround**; the only alternative is "print to PDF" from the
browser, which loses pagination, headers, and the cover page.

Many users affected (every engagement that has reached the deliverable
stage), no quick workaround, but not a security or data-loss issue.

# Long markdown note gets truncated at ~8000 chars

If a meeting note contains a markdown entry longer than roughly
8000 characters, the rendered view cuts off mid-sentence and the
"Show more" expand control never appears. The full text is still in the
database — the truncation is purely on the read path.

Workaround: click "Edit" on the note, which opens the textarea with the
full text. You can read it there or copy it out.

Impact: hits any meeting where the analyst pasted in a long synthesis
(maybe 5% of meeting records, mostly the deep-dive sessions). The
workaround is one extra click but does require edit permission on the
note, which not all viewers have.

This isn't blocking anyone day-to-day but it does occasionally hide
information from read-only viewers, which is a bug, not just cosmetic.
